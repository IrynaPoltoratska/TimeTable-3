# TableTime

Навчальний проєкт: веб-платформа для онлайн-бронювання столиків у кафе та ресторанах.

Виконано в рамках лабораторних робіт №2 «Створення структури веб-проєкту» та №3 «Використання каскадних таблиць стилів CSS для оформлення та адаптації вебсайту».

**Виконавець:** Ira, група КІ-43

## Структура проєкту

```
/tabletime
├── /images
├── /css
│   ├── style.css
│   ├── base.css
│   ├── layout.css
│   └── components.css
├── /js
├── index.html
├── catalog.html
├── restaurant.html
├── about.html
├── contacts.html
└── README.md
```

Папки `/images`, `/css`, `/js` створені відповідно до структури проєкту, вказаної у завданні лабораторної роботи.

## Сторінки

- `index.html` — Головна
- `catalog.html` — Каталог закладів
- `restaurant.html` — Сторінка закладу з формою бронювання
- `about.html` — Про нас
- `contacts.html` — Контакти

## Технології

Семантичний HTML5 (`header`, `nav`, `main`, `footer`), форма бронювання столика.

CSS (лабораторна робота №3):

- Зовнішні CSS-файли: `base.css` (типографіка), `layout.css` (розмітка), `components.css` (меню, картки, форми, кнопки, таблиці). Підключаються до головного `style.css` через `@import`.
- CSS Flexbox — шапка сайту та навігаційне меню.
- CSS Grid — сітка карток каталогу закладів і розмітка форми бронювання.
- Медіазапити (`@media`) — адаптація під телефони, планшети та настільні комп'ютери; бургер-меню для мобільної версії.
- Клієнтська валідація форми: HTML5-атрибути (`required`, `minlength`, `maxlength`, `type="email"`) та CSS-стилі для відображення помилок (`:user-invalid`).
- Препроцесори (Sass/Less) не використовувались.
