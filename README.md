# TableTime

Навчальний проєкт: веб-платформа для онлайн-бронювання столиків у кафе та ресторанах.

Виконано в рамках лабораторних робіт з дисципліни «Веб-орієнтовна розробка програмного забезпечення»:

- №2 «Створення структури веб-проєкту»;
- №3 «Використання каскадних таблиць стилів CSS для оформлення та адаптації вебсайту».

**Виконавці:** бригада №14 — Полторацька Ірина (КІ-43), Довгий Кирило (КА-44), Ніколаєнко Назар (КА-44).

## Технології

- **Семантичний HTML5** — `header`, `nav`, `main`, `article`, `footer`, форма бронювання столика.
- **Зовнішні CSS-файли** — стилі розділено на `base.css` (шрифти, типографіка), `layout.css` (розмітка, сітки, медіазапити) і `components.css` (меню, картки, форми, кнопки, таблиці). Усі вони підключаються до головного `style.css` директивою `@import`; сторінки підключають лише `css/style.css`.
- **Брендбук** — кольори `#2D6CDF`, `#F2A93B`, `#F7F8FA`, `#1E4FA3` (hover); шрифти Montserrat (заголовки) та Open Sans (текст), підключені з Google Fonts.
- **CSS Flexbox** — шапка сайту та навігаційне меню.
- **CSS Grid** — сітка карток каталогу закладів (1, 2 або 3 колонки) та розмітка форми бронювання.
- **Медіазапити (`@media`)** — адаптація під телефони, планшети (від 768 px) та настільні комп'ютери (від 1024 px); бургер-меню для мобільної версії, реалізоване на CSS без JavaScript.
- **Клієнтська валідація форм** — HTML5-атрибути (`required`, `minlength`, `maxlength`, `type="email"`) та CSS-стилі повідомлень про помилки (`:user-invalid`).
- **Препроцесори** (Sass/Less) не використовувались.

## Запуск

Збірка не потрібна: достатньо відкрити `index.html` у браузері. Для відображення шрифтів Montserrat і Open Sans потрібне підключення до інтернету.
